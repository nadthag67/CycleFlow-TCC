REFORMULE COMPLETAMENTE O DASHBOARD ATUAL DO CYCLE FLOW.

O resultado anterior ficou muito compacto e agrupou informações demais em poucos cards. Quero uma interface mais espaçosa, organizada, detalhada e visualmente hierárquica, inspirada na experiência de navegação de plataformas de acompanhamento menstrual como o Clue, mas sem copiar identidade visual, layout ou elementos proprietários.

O Cycle Flow é um site desktop de acompanhamento do ciclo menstrual, não um aplicativo mobile. O design deve parecer um produto web profissional de saúde e bem-estar.

1. PRINCIPAL OBJETIVO DO NOVO DASHBOARD

A página deve ter duas áreas principais claramente separadas:

ÁREA 1 — ACOMPANHAMENTO DO CICLO

Calendário menstrual grande.
Círculo/anel visual mostrando o ciclo atual.
Informações detalhadas do ciclo.

ÁREA 2 — ACOMPANHAMENTO DIÁRIO

Humor.
Sintomas.
Anotações.
Informações adicionais.

Não colocar tudo em uma única linha de cards.

Criar espaços generosos entre as seções, deixando cada funcionalidade visualmente independente.

10. ESTILO VISUAL

Quero uma estética semelhante à experiência de produtos modernos de acompanhamento menstrual, especialmente na forma de:

informações organizadas em blocos;
muito espaço em branco;
navegação simples;
calendário como elemento central;
indicadores visuais do ciclo;
componentes arredondados;
tipografia limpa;
poucos elementos por seção.

Não copiar o Clue.

Criar uma identidade própria para o Cycle Flow.

Evitar o visual excessivamente feminino/estereotipado.

Não usar rosa como cor dominante.

Utilizar principalmente:

branco/off-white;
lilás suave;
lavanda;
verde-menta;
pêssego;
tons neutros;
pequenos destaques em cores mais fortes.

As cores devem representar fases do ciclo de maneira sutil.

11. ESPAÇAMENTO E HIERARQUIA — MUITO IMPORTANTE

NÃO compactar a interface.

Quero que o usuário consiga identificar claramente:

Ciclo atual → Calendário → Registro do ciclo → Check-in → Histórico

Cada seção deve ter:

título próprio;
espaço superior e inferior;
card ou área visual própria;
hierarquia clara;
informações agrupadas logicamente.

Evitar colocar 4 ou 5 informações diferentes em uma única linha.

Evitar excesso de cards pequenos.

Evitar aparência de dashboard administrativo genérico.

O resultado deve parecer uma plataforma de saúde e acompanhamento pessoal, acolhedora e sofisticada.

12. RESPONSIVIDADE E IMPLEMENTAÇÃO

O design deve ser pensado primeiro para desktop/web, utilizando uma largura confortável e uma grade organizada.

Utilizar Auto Layout em todos os componentes.

Os componentes devem ser facilmente convertidos para:

HTML + CSS + JavaScript puro

Não utilizar elementos que dependam de animações complexas.

Todos os botões devem parecer elementos realmente interativos.

Criar estados visuais para:

hover;
selecionado;
ativo;
desabilitado.
RESULTADO ESPERADO

Quero que o Dashboard final tenha uma sensação de:

"Meu espaço pessoal para acompanhar meu ciclo"

e não:

"Uma tela cheia de informações comprimidas."

Priorize espaçamento, organização, profundidade das informações, calendário grande e círculo do ciclo como elementos principais.

O círculo do ciclo e o calendário devem ser os dois elementos visuais mais importantes da página.
